# 🐺 Wolf ERP V2

Base oficial do novo ERP da Wolf Colors.

## Tecnologias
- React
- Vite
- React Router
- Supabase (próxima conexão com banco/login)
- PWA (próxima fase)

## Como iniciar
1. Instale Node.js LTS
2. Abra a pasta no VS Code
3. Execute `npm install`
4. Execute `npm run dev`
